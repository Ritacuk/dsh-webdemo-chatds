# ChatDS 0.12.2 候选版使用与手动验收

## 安装

稳定版依然可从 DSH 插件管理器安装 `dsh-webdemo-chatds@0.12.1`。候选版请在独立 Profile 中用本地包验收。主聊天默认启用，Agent Side Chat 与 Data Sharing 可各自在插件管理器中启停。

```sh
dsh --profile chatds-preview --from-default-profile web --dump-config
dsh plugin --profile chatds-preview add /绝对路径/dsh-webdemo-chatds-0.12.2.tgz
dsh --profile chatds-preview
```

## 聊天界面设计

1. 打开 **ChatDS 设置 → 聊天界面设计 → 打开实时设计器**。也可从会话栏更多菜单打开。
2. 填写 DSH 入口名称并应用。清空名称恢复 WebChat。名称在 DSH 原生导航中即时更新，内部入口和插件管理器继续使用原有标识。
3. 切换左侧和右侧。拖动会话栏与聊天之间的分隔线调整宽度，或聚焦分隔线后使用方向键。窄窗口使用可收起的抽屉。尝试在两种位置使用搜索、分区、置顶和归档。
4. 按浅色、深色分别配置。原有外观页仍可控制跟随 DSH、浅色或深色。设计页的颜色与不透明度按区域即时预览。背景支持 1 MB 以内的 PNG、JPEG、WebP，助手头像上限 256 KB。
5. 在助手形象里设置全局昵称和头像，再从 DSH 模型目录选一项设置专属形象。新回复、历史回放和分支切换时检查显示。
6. 发送带思考的请求。默认策略在生成期间显示过程，完成后折叠。点击同一按钮展开和关闭。检查正文始终可见。
7. 从输入框聊天设置打开插件权限。在任意已有会话用鼠标、键盘或触摸切换授权。合上再打开并核对状态，尝试浅色、深色、窄屏和高缩放。

## 模型、语音与隐私

- 主模型与视觉能力沿用 DSH Provider、Model 和 Credential。图片理解需要目录中标为 Vision 的模型。现有附件提取继续使用原通路。
- 在 **模型与接口 → 语音识别** 选择 DSH 默认或已注册转写服务。显式选择的服务撤下后，转写会报不可用。这个设置不改变 DSH 系统默认服务。
- 在 **聊天界面设计 → 助手形象** 可打开本地自动朗读。它读取当前会话刚完成的新回复，要求系统提供匹配语言的本地语音。
- 在 **位置与隐私** 可保存手动城市。发送前勾选此条消息附加城市并检查预览。城市作为消息内容提供给所选模型，后续聊天历史与分享按原有规则处理。城市偏好和图片仅存于本浏览器。
- 同页可设置逐行匹配的关键词和本地提示。规则默认关闭，匹配时保留草稿，编辑发送也遵守此规则。
- 原生能力页显示当前 Profile 的翻译、跨会话搜索和随对话更新标题插件状态。参见[候选版原生接入说明](../reports/chatds-0.12.1/dsh-native-integration.md)。

## 更新与回退

候选包使用与 0.12.1 相同的组件标识和 Host 数据域。恢复稳定版见[回退说明](../reports/chatds-0.12.1/rollback.md)。
