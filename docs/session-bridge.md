# ChatDS Session 桥接（0.12.2-rc.1）

本版在 DSH 0.2.2-rc.5 以独立会话模式运行。现有聊天、分区、附件、分支、来源和同步状态沿用原存储。个人 DSH 工作区和原生会话不会进入 ChatDS 查询结果。无需手动迁移历史。

- **DSH 翻译。** 展开已完成的思考，点击「翻译此段」。页面会显示当前服务，确认后通过 Host 向 DSH Translator 发送这一段。Bing 和 Google 可用；付费路由要求受管原生 Session，独立 ChatDS 当前不调用。关闭思考会取消等待，成功译文在此 Profile 缓存。
- **兼容标题。** 默认使用确定性回退和已有标题事件。可在 ChatDS 本地记忆面板开启通用模型标题更新。它会在正常回合后另发一次小请求，按当前模型计费，手动标题优先。DeepSeek Rich 保持原单次对话内标题机制。
- **ChatDS 历史搜索。** 会话栏更多菜单中的「搜索聊天历史」搜索 ChatDS 当前可见分支的标题和正文。可按分区和日期筛选。点击结果会进入会话或定位消息。为限制资源消耗每次最多扫描 250 个会话及返回 50 条，截取时提示。
- **ChatDS 本地记忆。** ChatDS 设置的「长期记忆」可新建、编辑、删除和导出 JSON 备份。记忆可在全局或指定分区使用。启用注入会将匹配记忆发送给当前模型；保守字节上限限制注入量。自动提炼默认关闭，只对通用模型回合运行，并产生单独模型请求。
- **原生能力。** 状态页区分 ChatDS 隔离模式和官方插件运行状态。原生 Session 搜索工具继续面向原生 Session；ChatDS 搜索不把工具注入普通聊天。

使用 `npm install dsh-webdemo-chatds@next` 或 DSH 插件管理器选择预发布。恢复稳定版时指定 `dsh-webdemo-chatds@0.12.1`；回退版本忽略新增记忆、译文和行为字段，现有会话仍可打开。
