# ChatDS 0.12.1 数据共享

## 安装与升级

使用 DSH 插件管理器选择 ChatDS 0.12.1，再在插件管理器启用独立的「数据共享」组件。命令行也可以安装指定版本。

```sh
dsh plugin --profile web add dsh-webdemo-chatds@0.12.1
```

## 加入另一台设备

1. 在每台设备打开「数据共享 → 同步通道」，开启「允许局域网设备连接本机」。Windows 如提示授权，在系统窗口确认。两台设备需在同一局域网。
2. 在第一台设备打开「设备」，选择「设置设备同步密码」。使用至少 12 个字符，长而易记的短语更合适。
3. 在另一台设备选择「加入已有设备」。选择第一台设备，填写本机名称，输入相同密码。
4. 在「同步范围」选择要共享的聊天与接收设备，再预览及确认。已有聊天默认留在本机。

知道密码的人可以加入设备。移除设备会停止后续同步，已下载副本会留在对方设备。若被移除的人知道密码，请同时修改密码。

## 密码忘记与备份

原设备可以直接重设同步密码。也可以从仍获授权的设备通过局域网重设，原设备需要在线。其他设备再次连接时，使用新密码验证即可继续。原密码停止接受新设备。

原设备丢失时，可用备份密码在替代设备恢复共享身份和已接收记录，再设置新的同步密码。两者均不可用时，共享身份密钥无法找回，本机已有聊天仍按 DSH 的历史保存方式管理。「备份数据」备份的是共享身份、共享设置和接收记录。完整的本机聊天归档可在 WebChat 的聊天导出中另行生成。

## 从旧版升级与回退

0.12.0 预发布版本已经授权的设备与聊天继续使用原设备身份。设置新密码即可用新方式加入设备，原来的局域网配对仍可同步。更早的静态加密格式迁移会保留可读取的记录，并要求重新加入设备。Windows 旧版本如已配置了防火墙权限，请在升级前撤销旧版自己的规则，再在 0.12.1 使用新开关。若沿用了旧版开启状态，关闭再开启一次即可按当前端口配置权限，DSH 可继续运行。

升级前，复制对应 DSH Profile 和共享状态目录并保留加密备份。较旧插件可能无法读取 0.12.1 的共享状态。回退前先关闭局域网开关，撤销当前版本自己的规则，再恢复升级前的对应共享状态快照。保留升级后的 Profile 副本，避免覆盖升级期间新增的本机历史。
